🛡️ Cryptographic Architecture & Notice

Document Guardian implements strict zero-knowledge principles:

  • AES-256-GCM: Authenticated symmetric encryption with tamper detection for numbers and files.
  • PBKDF2 SHA-256 (100,000 rounds): Memory-hard Key Encrypting Key derivation.
  • HMAC-SHA256: Blind index for duplicate document detection without storing plaintext.
  • Zero Plaintext Storage: Cryptographic keys exist only in volatile RAM during active session.
